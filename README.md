# API Automation Demo Project

This project demonstrates **basic API automation testing** using **Python**, **Pytest**, and **Playwright**.  
It is designed as a learning project to practice API requests, response validation, and test automation structure.
  
## Features
- API request automation
- Response validation
- Pytest test framework
- Organized test structure
  
## Tech Stack
- Python
- Pytest
- Playwright
- VS Code (recommended IDE)

## Project Structure
- `reports/` – HTML reports
- `tests/` – Test cases
- `utils/` – API client helper
- `requirements.txt` – Python dependencies

## Prerequisites

Make sure you have the following installed:

- Python 3.8+
- pip
- VS Code (recommended)

## Clone the Repository

```bash
git clone https://github.com/simranshahdadpuri3005-lgtm/API-Automation-Demo-Project.git
```

Navigate to the project folder:

```bash
cd API-Automation-Demo-Project
```

## Install Dependencies

Install the required Python packages:

```bash
pip install -r requirements.txt
```

## Run Tests

To run all the tests inside the **tests** folder:

```bash
pytest tests/
```

You can run this command from the **VS Code terminal**.

## Generate Test Reports

Test reports will be generated in the **reports/** folder after execution.

## requirements.txt

```
playwright
pytest
pytest-playwright
```

## Purpose of the Project

This project is created to:

- Practice API automation testing
- Demonstrate pytest-based test structure
- Learn API request handling and validation
- Showcase automation skills
